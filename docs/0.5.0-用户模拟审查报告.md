## 发现与处理

### 代码审查

P1 是 A、B 模板代码块里仍有写给执行者的句子（“按下文继承”“有效人物档案”“身份继承ID”）。P2 包括：闸门不查上一场或上一集是否交完、STRICT 下忽略未完成的增量资产单元、SCENE_ASSETS 下多场共用资产被误拒、SCENE_ASSETS 与 BATCH_PREP 和入口规则冲突、返修回到较早场次时字段规则缺写、summary 缺续作字段、lint 的原台词检查静默跳过、lint 不解析适配稿镜头，以及试点证据的几处归因与计数错误。全部按审查意见修复并补测试，修复后构建 skills-v2。

待确认 7 项的处理：CDN 链接在提交的记录里替换为 `<redacted-url>`，原始记录不入库；首尾帧与参考图不能混用补了平台文档链接和读取日期；镜像改变的设计事实写进了观察记录和 I 模板写作要求；公开文档删去了密钥一句；收费任务按用户“全部做测试”的授权执行；COMPLETE 时只有 INVALID 单元、旧版本源的分段返修两项，在 validation.md 写明现有处理方式。
