# 0.6.0 外部依据修订

修订日期：2026-11-07，时区Asia/Shanghai。本次只改文字规则，不改变制作流程、`workflow_schema`或 `RUN_STATE`顶层字段，项目状态版本仍为1.9。技能包版本由0.5.0升为0.6.0。

本版没有做新的真实媒体测试。依据只来自外部公开研究与厂商官方文档，**未在本项目复现**，其模型、题材和数据范围与本项目的制作条件不同。这与0.5.0媒体试点（单一样例、自测观察）的性质不同，引用时不能混为一谈。

本版的分界不变：技能只负责把提示词写到可执行、无歧义、与剧本事实一致；画面最终由目标模型的能力决定。因此本版不写任何“这样写成功率多高”的承诺，也不按模型表现去改规则。实际结果按[媒体观察](../references/state-and-revision.md#s7-9)分范围记录，文字检查通过不等于媒体通过。

- NegT2IBench 等否定提示基准只读到检索摘要，没有核对原文，未写入规则。

## 证据强度的边界

- 否定与坐标系相关的三项依据都是文生图研究，本项目试点用的是`gpt-image-2-ext`生图和`wan3.0-video`视频，不是同一批模型，也不是同一代。文生图的结论能否迁移到视频，本次没有验证。
- 41.8个百分点与44.3%是22个模型的平均与最好成绩，不是本项目所用模型的成绩。这些数值只用于说明“向内／向外”在正文里存在坐标系歧义，**不写入规则，也不作为本项目模型成功率的预估**。
- 中程遗忘出自开源视频生成研究。本项目试点中门牌在约8秒出现，这一现象与机理方向一致，但不构成该项目模型出于同样成因的证明。
- 末帧接续：厂商官方文档明确推荐用它构建长视频，这是**能力层面的既有做法**；本项目试点只有一次样本，观察到的是**内容层面的错误继承**。两者不矛盾，本版因此不否连接续本身，只保留“接续前核验末帧”这一项目侧条件。早先一版草稿曾把接续降为非默认做法，依据不足，已按官方文档改回。
- Kulkarni 是学生研究报告，且本次只读到检索摘要与PDF链接，未逐页核对；它的数字只作成因说明，不承担“点名排除无效”这一结论的主要依据。
- 这些依据都不能替代[媒体观察](../references/state-and-revision.md#s7-9)。外部研究改变的是先验，实际媒体仍须逐项核对。

## 0.5.0结论的更新关系

0.5.0媒体试点报告“结论与规则修订”表中“点名排除是否有用尚无证据”一行，已被本版依据更新为负面结论。该行的原始观察（V2-A与V3-A的唯一单变量对照）仍然有效，按历史记录保留不改写；本版只改变了由该观察推出的结论强度。

“末帧接续继承错误”一行（V2-A末帧与V2-B）同样保留原观察，但由它推出的“接续不宜作为默认”在本版被撤销：厂商官方文档推荐用接续构建长视频，一次试点样本不足以推翻既有能力做法。现在的规则是“可以接续，但接续前核验末帧”。

## 未在本版执行的可选探针

以下四项都需要真实模型调用和费用，本版没有执行。它们是发现性质的工作，用于了解所配模型的行为，**不构成本版的发布条件**：本技能交付的是可执行文字，画面效果由目标模型决定，实际结果按[媒体观察](../references/state-and-revision.md#s7-9)分范围记录即可，不需要为此反推规则。

1. 手性偏好：同一首帧提示词分别要求左手／右手贴门，各生成数张，判断是否稳定偏向一侧。若稳定，则设计期可按[3.9](../references/shot-writing.md#s3-9)反向书写再翻转；若随机，文字层面无解，只能生成后翻转。
2. 开合朝向偏好：场景母图分别写向外开／向内开，判断是否稳定偏向“朝镜头”。
3. 生成单元长度与漂移：同一首帧、同一种子、同一文字，分别生成3秒、6秒、9秒，观察门牌的出现时刻是随经过时间固定，还是随请求总长推迟。这一项直接检验中程遗忘机理是否适用于本项目的模型。
4. 字幕与种子：有对白的片段用多个种子生成，判断重roll是否为可行补救，并据此确定尝试预算。
