# 格式范例

本文件示范0.5.0规则下几类交付的完整写法：人物身份母图、视频首帧图和一段两镜母稿。故事《渡口》为虚构样例，与任何项目、验收夹具无关；只示范格式和措辞，不复制其人物、场景或镜序。三段文字都通过了 `prompt_lint.py --strict` 检查，但该检查不核对空间关系、机位和轴线，这些按[镜头写法](shot-writing.md#s3-7)人工核对；文字没有用于实际生成，不代表模型效果已经验证。正式交付按当前项目的已确认设定和[完整模板](asset-templates.md)填写。

样例设定：画幅16:9，风格为下方母稿中的【全片风格】，单段上限15秒。周岚，31岁女性，165厘米；老陶，58岁男性，172厘米。原台词两句：周岚问“末班船走了吗？”，老陶答“走了，明早六点还有。”

```text
场《渡口·夜》·段《末班船》

总时长：10秒
时间码均相对本段0秒。
无字幕，无BGM
16:9

【角色锚定】

周岚
周岚是31岁的女性，身高165厘米，匀称偏瘦，黑色低马尾，额前几缕碎发。她穿深灰色棉麻长外套、浅灰色针织衫、黑色长裤和平底布鞋。开场她在栈道起点向尽头走，右手提着一盏白色纸灯笼，左手自然下垂。说话克制、轻声。

老陶
老陶是58岁的男性，身高172厘米，偏瘦，花白短发，穿藏蓝色旧棉袄和深色长裤。开场他坐在系船桩旁的木箱上，双手放在膝盖上，望着河面。说话平淡、简短。

【全片风格】
风格化三维动画电影，简化的体块与柔和的哑光着色。夜色以低饱和的青蓝为底，灯笼和栈道小灯给出小块暖黄，肤色保留自身颜色。成像干净，轮廓稳定，暗部仍能看清人物轮廓和手部。

【整体描述】

场景与环境：
夜里河边的木栈道，栈道从画面左下方伸向右上方，尽头有一根系船桩，桩顶挂着一盏小灯。栈道两侧是平静的河面，对岸有几点远灯。栈道上只有周岚和老陶。

本段光线、色彩与环境基调：
系船桩的小灯从画面右上方照亮栈道尽头和老陶；周岚的纸灯笼在她身边投下一小圈暖光，随她行走移动。其余区域是低亮的青蓝夜色，河面有细碎的倒影。

开场状态与本段范围：
开场周岚在栈道起点向尽头走，右手提着纸灯笼；老陶坐在木箱上望着河面。随后她走到老陶左后方一步停下，两人各说一句，结束时老陶仍望着河面，周岚站在他左后方。

镜头一 {
时间：0–5秒。

景别、机位：
全景（Wide Shot，WS），平视（Eye Level），摄影机在栈道起点、周岚身后略偏左，高约1.5米，朝栈道尽头。画面上边缘在系船桩小灯上方，下边缘在栈道木板处，两人的全身都在画面里。

运镜及拍摄主体：
跟拍（Tracking Shot），主体是周岚走向老陶的过程。起幅是周岚在画面左下方背对镜头起步；摄影机以她的步速沿栈道向前移动，与她保持约两米距离；落幅时她在老陶左后方一步停下，摄影机随之停住。

构图：
引导线（Leading Lines），栈道两侧的栏杆把视线引向尽头的系船桩和老陶；周岚始终在画面左侧三分线附近。

画面内容：
0–4秒，周岚提着纸灯笼匀速走向栈道尽头，灯笼随步子轻轻摆动；老陶坐着不动，望着河面。4–5秒，她在老陶左后方一步停下，灯笼停稳。

声效：
脚步踩在木板上的轻响，河水轻拍栈道。
}

镜头二 {
时间：5–10秒。

景别、机位：
侧面双人中景（Medium Two Shot），平视（Eye Level），摄影机固定在栈道尽头靠河一侧、约1.2米高，从两人的侧前方回看栈道。老陶坐在画面右侧前景，侧脸朝向画面右侧的河面；周岚站在他左后方一步，在画面左侧、纵深稍远处。画面上边缘在周岚头顶上方，下边缘在老陶膝盖处，两人的脸都清楚可见。

运镜及拍摄主体：
静止镜头（Static Shot），主体是周岚提问和老陶回答的交流。摄影机全程保持同一位置。

构图：
对角线（Diagonal），老陶在右下前景、周岚在左上中景，两人的头部连成一条斜线；纸灯笼的暖光照亮周岚的下颌和老陶的右肩，河面与对岸远灯在画面右侧纵深。

画面内容：
5–6秒，周岚看着老陶的侧脸，右手仍提着灯笼。6–7.5秒，她轻声问：
周岚（轻声，看着老陶）：“末班船走了吗？”
7.5–8秒，老陶转头看了她一眼，又转回去望着河面。8–10秒，他平淡地回答：
老陶（平淡，望着河面）：“走了，明早六点还有。”
说完他继续望着河面，周岚站在原处。

声效：
河水轻拍栈道；两句对白之间约半秒的停顿。
}

【禁止项】

河面上没有船，栈道和栏杆上没有文字或标牌，画面里只有两人。无水印。
```
