# 镜头连接与转场执行

本文件用于已采用本技能项目中的段内切镜、相邻正式段承接，以及用户指定的素材连接检查。与[镜头写法](shot-writing.md)、[时长与分段](timing.md)、[模型适配](model-adaptation.md#s5-2)和[状态规则](state-and-revision.md)配合使用。普通切换能表达时直接采用；只读取当前连接需要的方法，不增加制作阶段、独立导演方案或固定转场配额。

方法吸收自用户提供的《AI分镜转场Skill_V2.0_独立完整版》v2.0（2026-11-04），已按本技能规则改写。该TXT、同名技能、默认平台及安装配置都不是运行依赖。

<a id="transition-entry"></a>
## 连接判断与读取时机

先明确本处让观众理解的关系、前后事实与揭示时点，再选择连接依据。整场分析确定关系，预算阶段登记必要相位与时间，正式段把具体接法写进既有镜头栏目；真实素材返回后才确定实测出入点。没有媒体也可完成文字计划，不能把动态检查设成全部文字制作的前驱。

| 连接依据 | 优先考虑 | 关键条件 |
|---|---|---|
| 信息、动作或空间已经自然交接 | 普通硬切或连续观察 | 必要信息可读，后镜承接实际状态 |
| 同一动作继续，或不同主体做相似动作 | [动作匹配](#transition-action) | 相位向前、轨迹与速度趋势可接 |
| 轮廓、主体位置或主要色块呼应 | [图形、构图与颜色](#transition-graphic) | 透视、占比、裁切与承接区域有依据 |
| 人物看向随后展示的对象 | [视线衔接](#transition-eyeline) | 目标在世界中的方位、高度、机位成立 |
| 有合理不透明前景或黑暗来源 | [遮挡与黑场](#transition-occlusion) | 实际完整覆盖，进入退出可接 |
| 摄影机甩出再甩入 | [甩镜](#transition-whip) | 摄影机方向、背景掠过、速度与落稳可接 |
| 声音先入、延续或音色节奏呼应 | [声音连接](#transition-sound) | 声源、起止、对白与揭示受到保护 |

需要生成两端之间的连续过渡时，再评估[桥接素材](#transition-bridge)。桥接是素材实现路线，不是每处连接的默认步骤。可组合方法，但每项应解决具体问题，不为展示技法增加事件、道具、空镜或生成任务。

<a id="transition-record"></a>
## 连接事实与记录归属

简单切换沿用正文及已有检查即可；需要跨段承接、精确匹配或素材返修时，在现有记录中补齐适用事实：

- 连接定位：所属formal_id、实际镜头标识及各自版本；有媒体时关联素材版本和选定出入点。
- 叙事目的与连接依据：本处为何切、观众应辨认什么、何时允许揭示。
- 不变量与允许变化：按本处目的确定。换景可保留身份与动作，跨主体匹配可允许身份不同；换装、时空或光照变化仍须有剧本或已确认设计依据。
- 三类方向分别描述：主体在画面中的运动、摄影机运动、人物在场景中的朝向或目标位置。不把画面左右当作固定世界坐标。
- 前后状态：动作相位、位置、姿态、左右手及道具、持续声源、必要地标、光照和可见信息；注明已完成与下一尚未开始的内容。
- 素材职责、实际依赖及检查范围：身份或构图参考不等于严格首尾帧；按[素材职责](asset-templates.md)和当前模式的真实能力使用。

跨正式段的计划归transition_plan；段内连接落实在母稿并由transition_review核对，文字检查继续使用check_scope=TEXT。真实画面、动态、声音与拼接观察归所属step_ledger.media_observations，连接记录引用其observation_id。各处引用同一版本，不另建剧情覆盖账本或RUN_STATE顶层字段。

无素材的状态标为计划或据用户描述，不填虚构时码、坐标或帧号。普通选镜按现有授权自主完成；关键决定、固定边界及原文保护继续服从[技能入口](../SKILL.md)。

<a id="transition-edit-points"></a>
## 剪辑出入点与文件边界

A出点是前镜最终保留的最后画面，B入点是后镜最终保留的第一画面，可以位于原素材中间。先选择符合剧情、动作、对白和揭示要求的保留区间，再设计连接；不机械使用物理末帧或首帧，也不能为找好接点剪掉必要内容。

同一镜头、生成文件和正式段是不同单位。文件边界不自动产生切镜或停顿；选中间出点也不自动改变源内覆盖。裁剪后若必要内容或既定首尾不再完整，按[返修规则](state-and-revision.md#s7-6)处理，不能仅因接顺而判定当前正文仍已实现。

动作和甩镜不能只看一对静帧。可先取A出点前、B入点后各3～5帧初筛，必要时扩大范围并正常速度播放；这不是固定验收数量。核对相位、轨迹、速度趋势、停住再启动、倒退和重复起手。无帧率与真实时间依据时不推算精确速度或秒数。

<a id="transition-action"></a>
## 动作匹配

同一主体延续动作时，B从A选定相位继续下一阶段，不先复位或重复起手；不同主体做匹配动作时，优先保持轨迹、相位和注意位置，身份是否相同由剧情决定。身体左右、物件归属和银幕运动分别核对。

已有素材可临时叠放接点比较关节与位置。位移、缩放可修构图，小幅调速须有现有授权且重算声音与预算；这些操作不能修错手、相反轨迹或动作顺序倒退。从零制作时可先给两侧计划，B的实际输入与动态结论待A出点返回后校准，不因此提前执行下一正式段。

奔跑步态、拔刀、腾空等精确相位需要实际连续运动依据。静态姿势、固定机位和相同提示词不能证明动态已匹配；必要时提出缩小精确接续范围或补素材的方案，保留用户明确要求的动作。

<a id="transition-graphic"></a>
## 图形、构图与颜色

图形匹配核对完整轮廓、中心、占比、观察角度及裁切。圆与明显椭圆不能靠等比缩放对齐；材质各自成立，不把轮廓呼应写成融化或物体变形。两张合格静图已能表达时可以直接剪接，需要运动时才安排相应素材。

构图匹配同时核对主体位置、景别、姿态、朝向和比例，不只对齐眼睛而忽略肩宽或身体动作。身份参考与姿态／构图参考分别声明职责。普通叙事切换不要求每镜构图一致。

颜色匹配明确承接的大色块、区域和位置，保持各场自然材质与光照。只有零散同色可称色彩呼应，不宣称无缝匹配。先考虑可用素材的位移、缩放或适当调色；没有实际测量不报像素级吻合。

<a id="transition-eyeline"></a>
## 视线衔接

明确人物看谁或什么、目标相对人物的方向、高度与距离，以及后镜的观察位置。区分对视、人物看物与主观镜头，沿已有地标和轴线核对；后镜中对象的画面位置不能机械照搬前镜眼神指向。

前镜让观看方向可辨，后镜让目标及其关系可读。是否延迟揭示、是否改变时空或光照按剧情决定，不为视线转场增加反应、目标或人物已知信息。

<a id="transition-occlusion"></a>
## 遮挡与黑场

遮挡切依赖实际完整覆盖。镂空树叶、碎发、透明玻璃或局部暗面仍可能漏出背景，不能据此宣称能藏住切换。优先使用已有合理前景或明确的后期合成方案，不为了转场新增剧情道具。

按实际需要描述“A可见→遮挡进入→完整覆盖并隐藏切换→遮挡退出→B可见”，不把这些相位强拆成镜头或固定时长。允许变化发生在被隐藏的合适阶段，未到揭示时点不提前露出新状态。B退出应接住真实遮挡的颜色、纹理和运动；清晰B图作为严格首帧时，与首帧全遮挡要求冲突，须调整输入职责或路线。

黑场有具体暗处、贴近不透明物体等来源，或明确采用后期黑场。边界真正全黑、持续时长和退出条件都按实际素材核对；不凭不存在的门洞或晴天远景保证能从黑暗精准退出。

<a id="transition-whip"></a>
## 甩镜

摄影机向右横摇时，静止背景通常向左掠过；主体向右移动本身不是摄影机右甩。明确摄影机转向、画面运动和主体任务，避免随机旋转、回摆或无因停顿。

A甩出时出点仍有相应运动，B从可匹配的运动状态减速落稳，最后保留必要辨认时间。清晰B图若被指定为严格首帧，不能同时要求第一帧完全模糊；只有模式已确认支持时，才可把该图改作落稳尾帧目标，否则给可用模糊入点、独立素材或后期方向模糊路线。

实际检查模糊方向、程度、速度趋势、曝光和落稳。形变不能因模糊就判合格，不用加长叠化掩盖重影；有人行走、水流或烟雾等时间方向时，不将倒放作为通用修复。

<a id="transition-sound"></a>
## 声音连接

声音先入（J-cut）是B声音先出现在A画面下；声音延续（L-cut）是画面进入B后A声音仍持续。声音匹配可用不同声源的音色、节奏或音高接续，不要求一定重叠。已有声音可安排音轨，无需因此重生画面。

记录声源与版本、进入退出条件、承载画面、对白保护及实际试听范围。跨切点音轨不能提前泄露信息、重复话轮或截断必要尾音；一句跨文件仍按[话轮与声音边界](timing.md#s6-5)落实唯一speech_id及连续音频。缺声音时可交付描述或计划，不承诺模型能精确生成。

声音检查需要真实听取；静帧、波形或文字描述不能证明响度、听觉匹配和对白可懂度。试剪偏移按素材调整，不把固定半秒或一秒当作标准。

<a id="transition-bridge"></a>
## 条件式桥接素材

用户要求或连接确需桥接时，先核对当前模式能否执行所需控制。能上传两张图不等于支持严格时序首尾帧，更不保证两状态可自然到达；未知能力按[模型适配](model-adaptation.md#s5-2)处理，不阻断与其无关的通用文字交付。

需要首尾控制时，使用“A选定出点→桥接首帧，B选定入点→桥接尾帧”，保存两端素材版本、不变量、允许变化和实际输入职责。缺任一真实边界可给条件明确的计划，不能声称已绑定或动态验证。

桥接是所属正式段的素材实现，可对应额外生成任务，不另增formal_id或剧情覆盖。新增保留时间、替代原区间、重叠和剪除分别按[成片与素材时钟](timing.md#s6-7)核算；增加准备段不能伪装原窗口已达标。保护必要动作、台词与阅读窗口，改变固定时长、已确认边界或剧情时走原决定及返修规则。

真实生成后分别检查A→桥接、桥接内部、桥接→B。裁去重复边界画面后重新检查动作与声音，不能只查桥接内部。换景、变装、复杂动作和卡拍同时发生时指出具体冲突，给减少同时变量或后期路线的选择，不擅自删掉用户坚持的目标。

<a id="transition-review"></a>
## 检查与定向修正

文字方案、静态素材、动态素材、声音和实际拼接分别报告实际检查范围；沿用[媒体观察](state-and-revision.md#s7-9)的scope、evidence与版本。假设反馈只用于推理，没有媒体不生成空验收报告，不把TEXT通过写成MEDIA通过。

先区分静态位置／轮廓不符、动作相位／左右手错误、模式控制不足和剪辑点不合适；用可定位证据确定本次主要修正，保留有效内容。可记录“症状与证据→原因假设→本次改动→保留项→结果”。

不设固定失败次数就必须简化的通用规则。用户已设重试或成本上限时在project_decisions保存依据并遵守；没有新证据或可验证改动时不机械重复同一方案，报告缺口和可选路线。文字返修按原流程完成，实际生成、剪辑和收费重投继续以用户授权及可用工具为准。

前段改版先比较出点和相邻运动是否改变，再沿实际依赖标记相关连接待复核；仍成立的后段保留。只有母稿事实、覆盖、物理末态或观看信息改变时，按原[失效规则](state-and-revision.md#s7-6)处理文字依赖；媒体接缝失败本身不撤销正确母稿。修正提示词不代表旧媒体已修复，需检查新结果才能更新对应媒体结论。
