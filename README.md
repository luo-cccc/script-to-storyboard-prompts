# 剧本转分镜提示词

将中文剧本、剧情或动作笔记整理为项目分析、人物场景道具图片提示词、集场规划、整场时长预算与分段，以及逐段视频提示词。

计划中的技能标识：`script-to-storyboard-prompts`。

**当前阶段：规范与技能化方案已整理，技能包尚未制作或安装。** 本仓库目前提供完整的单文本规范、技能化设计和资料研究，不包含可安装的 `SKILL.md`。

## 当前使用方式

下载单文本规范 v1.8，将全文复制或上传给支持长文本的模型，并提供剧本。可以这样发起：

> 请按这份规范处理剧本，先完成项目分析，并让我确认视频画幅、画面质感和单段时长上限。

规范默认逐步交付文字。提示词完成不代表图片、视频或声音已生成；实际媒体生产需要另行明确要求，并依赖实际可用工具。

## 制作流程

1. 项目分析及三项制作条件确认。
2. 人物资产：首次同轮交付身份母图与四视图提示词。
3. 场景母图与核心道具提示词。
4. 按集规划，登记事件链与增量资产。
5. 整场分析，明确事实、空间、台词及揭示顺序。
6. 整场预算与合法分段，记录首尾承接。
7. 逐段完整视频母稿；指定模型时核验能力和素材后派生提交适配稿。

保留原台词、因果、结果与揭示顺序；先算整场时长再拆段；剧情覆盖、历史返修和状态恢复沿用同一套记录。
