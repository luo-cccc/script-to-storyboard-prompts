# 剧本转分镜提示词

将中文剧本、剧情或动作笔记整理为项目分析、人物场景道具图片提示词、集场规划、整场时长预算与分段，以及逐段视频提示词。

技能标识：`script-to-storyboard-prompts`。技能包版本：**0.1.0**，规则基线与项目状态版本：**1.8**。

## 安装

将 `SKILL.md`、`references/` 和 `evals/` 一起复制到支持技能的客户端目录，保留这一层目录名：

```text
~/.agents/skills/script-to-storyboard-prompts/
├── SKILL.md
├── references/
└── evals/
```

仓库根目录本身就是技能包。也可将完整仓库克隆到上述目录；`docs/`、`specs/` 和 README 是说明资料，不是运行时必读前驱。

ZCode 支持用户级 `~/.agents/skills/`。安装后在新会话中从“设置 → Skills”或输入框 `/` 菜单确认发现情况。已有同名目录时先比较，不直接覆盖；用户 `.zcode/skills/` 中的同名技能可能优先加载。其他客户端的目录、刷新和调用语法以该客户端说明为准。

调用示例：

> 使用“剧本转分镜提示词”（script-to-storyboard-prompts）处理这份剧本，先完成项目分析，并让我确认视频画幅、画面质感和单段时长上限。

后续在该项目中说“继续”，每轮只完成当前下一单元。已采用其他制作流程的项目不会自动切换。

## 制作流程

1. 项目分析及三项制作条件确认。
2. 人物资产：首次同轮交付身份母图与四视图提示词。
3. 场景母图与核心道具提示词。
4. 按集规划，登记事件链与增量资产。
5. 整场分析，明确事实、空间、台词及揭示顺序。
6. 整场预算与合法分段，记录首尾承接。
7. 逐段完整视频母稿；指定模型时核验能力和素材后派生提交适配稿。

保留原台词、因果、结果与揭示顺序；先算整场时长再拆段；剧情覆盖、历史返修和状态恢复共用一份项目状态。普通摄影与不改变剧情的细节由模型设计，不增加独立分镜表或关键帧审批。

默认逐步交付文字。提示词完成不代表图片、视频或声音已生成；实际媒体生产需要明确要求和实际可用工具。制作项目的剧本、状态、资产记录、预算和产物保存在各自项目目录，避免写入技能目录。

## 验证说明

已完成迁移、链接和安装副本检查，并进行了静态审查及三组10轮模拟用户测试。**当前验证结果为部分通过**：模拟仍出现人物用光方向矛盾和文字检查漏检；取消适配的状态表达尚未标准化。完整结果见[验收记录](docs/技能包实施与验收记录.md)。

`evals/scenarios.md` 提供44个待执行人工用例，不会自动运行。新会话发现与自动触发、完整端到端制作和真实媒体效果尚未验证，不能以文字检查代替。
