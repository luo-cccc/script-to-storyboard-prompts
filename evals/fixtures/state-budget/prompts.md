# 合成机械测试正文

这些是范围缩小的可读记录，供覆盖与引用测试；不满足完整母稿模板，不作为H行为验收的已完成创作前驱。

<a id="formal-1"></a>
## FORMAL_1 / P1

时间码相对本段0秒。0–10秒：右掌已抵住关闭的门，持续向前推至半开。段尾右掌保持接触，门仍向开启方向运动，下一段继续相同推门动作。没有对白。

<a id="formal-2"></a>
## FORMAL_2 / P2

时间码相对本段0秒。0–10秒：从门半开、右掌持续抵门的动作相位继续，推至全开；不再重做起手或半开前的过程。段尾门全开，右掌仍抵门。没有对白。

<a id="formal-3"></a>
## FORMAL_3 / P3

时间码相对本段0秒。0–4秒：门全开，右掌离开门后自然放下，人物站定；门保持全开。没有对白。
