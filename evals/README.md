# 验收资料

本目录保存人工验收规格、确定性夹具和历次运行证据。运行技能时不需要它；维护者在完整仓库中复跑回归和追溯结论时读取。

| 路径 | 内容 |
|---|---|
| `scenarios.md` | 82 个人工行为用例（74 个业务、8 个触发）及 R01–R16 规则覆盖索引 |
| `fixtures/state-budget/` | 可移植的状态与预算回归数据，供 `tests/` 与 D 类检查使用 |
| `media-pilot/` | 0.5.0 媒体试点的调用、抽取、汇总与脱敏脚本，只作维护工具 |
| `runs/` | 按版本保存的运行记录与审查归档，只追加，不覆写 |

## runs 目录约定

- 文件名 `<版本>-<用途>.json`：`preacceptance` 是修订前快照，`acceptance` 是发布时的最终快照，`before-user-review` 是用户模拟前的中间快照。同名新运行使用新文件名，不覆盖旧记录。
- 记录包含受测文件 SHA-256、原始标准输出、退出码和测试数量；输入在运行中变化或未发现测试时不报告通过。
- `0.4.1-user-review/` 与 `0.5.0-user-review/` 是用户模拟与独立评判的归档。归档里的 Markdown 和 Python 文件加 `.txt` 后缀，字节不变；`archive-index.json` 逐个登记来源、哈希和 `duplicate_of`（夹具副本与已归档文件逐字节相同时只保留一份）。
- `0.5.0-media-pilot/` 保存脱敏后的任务记录、提示词、观察和汇总。生成的图片与视频、未脱敏的 `records-raw/`、抽帧目录按 `.gitignore` 排除；记录里的 CDN 链接替换为 `<redacted-url>`。
